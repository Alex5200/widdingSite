# 🎉 Свадебный сайт-приглашение

Сайт-приглашение на свадьбу Александра и Алевтины с адаптивным дизайном.

## 🚀 Быстрый старт

### Вариант 1: Использование Node.js сервера (рекомендуется)

```bash
# Запуск сервера
npm start

# Или напрямую
node server.js
```

После запуска откройте в браузере: **http://localhost:3000**

### Вариант 2: Простой HTTP сервер Python

```bash
# Python 3
python -m http.server 3000

# Python 2
python -m SimpleHTTPServer 3000
```

### Вариант 3: Просто открыть файл

Дважды кликните по файлу `index.html` для открытия в браузере.

## 📱 Доступ с телефона в локальной сети

Если вы хотите открыть сайт с телефона в той же WiFi сети:

1. Узнайте ваш локальный IP-адрес:
   - **Windows**: выполните `ipconfig` в командной строке
   - **macOS/Linux**: выполните `ifconfig` или `ip addr`

2. Откройте на телефоне: `http://<ВАШ_IP>:3000`
   
   Например: `http://192.168.1.100:3000`

## ⚙️ Настройка

### 1. API ключ Яндекс.Карт

Получите бесплатный ключ на [developer.tech.yandex.ru](https://developer.tech.yandex.ru/)

Замените `your-api-key` в файле `index.html` (строка ~186):

```html
<script src="https://api-maps.yandex.ru/2.1/?apikey=your-api-key&lang=ru_RU"></script>
```

### 2. Замена фотографий

Замените изображения в папке проекта:
- `images/bride.jpg` - фото невесты (Алевтина)
- `images/groom.jpg` - фото жениха (Александр)

Или измените пути в `index.html`.

### 3. Изменение деталей

Отредактируйте `index.html`:
- Дата свадьбы
- Время мероприятия
- Адрес ресторана
- Программа дня
- Контактная информация
