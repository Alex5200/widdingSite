# 💕 Сайт-приглашение на свадьбу

Красивый и адаптивный сайт-визитка для свадьбы с современным дизайном.

## 🌟 Особенности

- **Адаптивный дизайн** - отлично смотрится на телефонах, планшетах и ПК
- **Интеграция с Яндекс.Картами** - показываем гостям место проведения
- **Фото жениха и невесты** - красивые карточки с фотографиями
- **Тайминг дня** - подробная программа мероприятия
- **RSVP форма** - гости могут подтвердить присутствие
- **Плавные анимации** - современный UX с анимациями при скролле

## 📁 Структура проекта

```
wedding-website/
├── index.html      # Основная HTML-разметка
├── styles.css      # Стили и адаптивный дизайн
├── script.js       # JavaScript функционал
└── README.md       # Документация
```

## 🚀 Быстрый старт

1. Откройте `index.html` в браузере
2. Для работы карт получите API-ключ Яндекс.Карт: https://developer.tech.yandex.ru/
3. Замените `your-api-key` в index.html на ваш ключ

## ⚙️ Настройка

### Изменение данных

**В index.html замените:**
- Имена жениха и невесты
- Дату свадьбы
- Название ресторана
- Адрес и координаты
- Время мероприятия

### Настройка карты

В файле `script.js` измените координаты:

```javascript
const restaurantCoords = [55.751244, 37.618423]; // Ваши координаты
```

Чтобы получить координаты вашего ресторана:
1. Откройте Яндекс.Карты
2. Найдите нужный адрес
3. Кликните правой кнопкой мыши → "Что здесь?"
4. Скопируйте координаты

### Замена фотографий

Замените ссылки на изображения в `index.html`:

```html
<!-- Фото жениха -->
<img src="ВАША_ССЫЛКА_НА_ФОТО" alt="Имя жениха">

<!-- Фото невесты -->
<img src="ВАША_ССЫЛКА_НА_ФОТО" alt="Имя невесты">
```

Можно использовать:
- Локальные файлы (положите в папку с сайтом)
- Хостинг изображений (Imgur, Google Photos)
- Unsplash (как в примере)

## 🎨 Цветовая схема

- **Основной цвет**: #d4a574 (золотисто-бежевый)
- **Фон**: #faf8f5 (светло-кремовый)
- **Текст**: #2c2c2c (темно-серый)

Чтобы изменить цвета, отредактируйте CSS переменные в начале `styles.css`:

```css
:root {
    --primary-color: #d4a574;
    --secondary-color: #f5e6d3;
    --text-dark: #2c2c2c;
}
```

## 🔧 Дополнительные функции

### Отправка RSVP формы

По умолчанию форма показывает alert. Для реальной отправки данных:

**Вариант 1: Telegram Bot**
```javascript
// В script.js замените обработчик формы
fetch('https://api.telegram.org/botTOKEN/sendMessage', {
    method: 'POST',
    body: JSON.stringify({
        chat_id: 'CHAT_ID',
        text: `Новый ответ: ${formData.name}, ${formData.attendance}`
    })
});
```

**Вариант 2: Google Sheets**
Используйте Google Forms или Apps Script для сбора данных.

**Вариант 3: Email**
Используйте сервисы типа Formspree или EmailJS.

### Таймер обратного отсчета

Раскомментируйте в `script.js`:
```javascript
initCountdown();
```

И добавьте HTML элемент для отображения.
